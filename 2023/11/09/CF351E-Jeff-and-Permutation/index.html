Solution

2200 不会做，警戒。

观察到读入进来的数的正负没有关系，所以先把他全部取绝对值。

如果 ai<aja_i<a_jai​<aj​，则无论怎么改变 aia_iai​ 的正负对答案无影响。影响答案的是 aja_jaj​ 的正负。这样每个 aja_jaj​ 独立。

只需要对讨论 aja_jaj​ 的正负分别对答案的影响，取 min⁡\minmin 即可。

int n,a[maxn],l,r,ans;
signed main(void){
//	freopen("1.in","r",stdin);
	int i,j;
	read(n);
	for (i=1;i<=n;i++) read(a[i]),a[i]=abs(a[i]);
	for (i=1;i<=n;i++) {
		l=r=0;
		for (j=1;j<=n;j++) if (i^j) {
			if (a[j]<a[i]) {
				if (j<i) l++;
				else r++;
			}
		}
		ans+=min(l,r);
	}
	printf("%d",ans);
	return 0;
}
