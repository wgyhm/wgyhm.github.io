Solution

令 s=∑x∈Axs=\sum _{x\in A} xs=∑x∈A​x 观察到那个贡献形式为 (∣A∣−1)s2(|A|-1)s^2(∣A∣−1)s2。

考虑容斥，将**gcd⁡\gcdgcd恰好为 111** 转化为 gcd⁡\gcdgcd 至少为 kkk 的倍数。

令 fkf_kfk​ 为 gcd⁡\gcdgcd 恰好为 kkk 的贡献，gkg_kgk​ 为 gcd⁡\gcdgcd 为 kkk 的倍数的贡献，因为有 gk=∑k∣tftg_k=\sum\limits_{k|t}f_tgk​=k∣t∑​ft​，根据莫比乌斯反演有 fk=∑k∣tgtμ(tk)f_k=\sum\limits_{k|t} g_t\mu(\dfrac{t}{k})fk​=k∣t∑​gt​μ(kt​)。

现在只需要计算 gkg_kgk​。把能被 kkk 整除的数字拎出来。

发现如果递推去计算那个贡献形式是不好算的，需要组合数什么的。贡献形式实际上是 ∑xy,x∈A,y∈B\sum xy,x\in A,y\in B∑xy,x∈A,y∈B，考虑直接计算每一对数的贡献，记元素总数为 ccc ，根据 xxx 是否等于 yyy 讨论：

  • x=yx=yx=y ，则 xxx 存在于 A,BA,BA,B 集合中，选出一个在 AAA 但是不在 BBB 中的数有 c−1c-1c−1 种方案，其他可选可不选有 2c−12^{c-1}2c−1。
  • x≠yx\not = yx=y ，讨论 xxx 在不在 BBB 种，总贡献是 (c−2)2cnt−3+2cnt−2(c-2)2^{cnt-3}+2^{cnt-2}(c−2)2cnt−3+2cnt−2。

然后直接计算，快速幂不预处理也能过。

注意到 ccc 即存在直接相乘，有存在于指数中，所以不能随意取模。

const int mod=998244353;
int power(int x,int y=mod-2) {
	int sum=1;y%=(mod-1);
	while (y) {
		if (y&1) sum=sum*x%mod;
		x=x*x%mod;y>>=1;
	}
	return sum;
}

void getprime(int n) {
	vis[1]=mu[1]=1;int i,j;
	for (i=2;i<=n;i++) {
		if (!vis[i]) prime[++cnt]=i,mu[i]=-1;
		for (j=1;j<=cnt&&prime[j]*i<=n;j++) {
			vis[i*prime[j]]=1;
			mu[i*prime[j]]=-mu[i];
			if (i%prime[j]==0) {mu[i*prime[j]]=0;break;}
		}
	}
	for (i=1;i<=n;i++) if (mu[i]!=0&&(int)O[i].size()) {
//		gdb(i,O[i].size(),mu[i]);
		int res=calc(i);
		if (mu[i]==1) add(ans,res);
		else add(ans,mod-res);
	}
}
