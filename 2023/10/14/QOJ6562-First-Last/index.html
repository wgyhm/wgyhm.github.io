Description

https://qoj.ac/contest/1248/problem/6562

注意到重要性质出现在首尾的字符数量 ≤3\le 3≤3。

Solution

首先先压缩成 999 个点。原来的博弈可以看作 999 个点以及很多条有向边（包括自环）构成的有向图。

注意到：

  • 如果一个点有两个自环，那么删去这两个边，局面胜负关系不变。
  • 如果存在边 (x,y)(x,y)(x,y) 和 (y,x)(y,x)(y,x)，那么删去这两个边，局面的胜负关系不变。

具体证明的话可以通过讨论这个点的胜负关系，然后发现另外一个人可以绕回去来搞。

把每种边（如果有的话）删去到最多一条，这样整个图非常稀疏。直接跑暴力就好了。

int nums[4][4],to[4][4],e[4][4],id[105],cnt;
int n,ans;
bool dfs(int x) {
	int flag=0,vis=0,i;
	for (i=0;i<3;i++) if (e[x][i]) {
		flag=1;e[x][i]--;
		vis|=(dfs(i)==0);
		e[x][i]++;
	}
	if (!flag) return 0;
	else return vis;
}
