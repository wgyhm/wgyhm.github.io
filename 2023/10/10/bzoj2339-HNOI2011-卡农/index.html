[HNOI2011] 卡农

https://www.luogu.com.cn/problem/P3214

Solution

很经典的题目啊。

其实题目本质上，就是从 2n−12^n-12n−1 个集合中选，有四个限制：

  • 无序
  • 集合非空
  • 每个音阶出现的次数为偶数
  • 每个集合不相同

令 fif_ifi​ 表示选了 iii 个集合，满足上面的要求。

首先考虑第三个限制，利用容斥的思想，其实只要随意选 i−1i-1i−1 个集合，就能唯一确定剩下的那个集合使得满足第三个限制。

但是如果要满足无序的话就很烦。考虑把无序转化为有序，不管这个限制，最后除以 m!m!m! 。

回到前文，现在我们不保证无序后，选择的集合数量为 A2n−1i−1A_{2^n-1}^{i-1}A2n−1i−1​ 。然后我们还要保证剩下那个集合不是空集。只要前 i−1i-1i−1 个不满足出现的次数为偶数即可，减去 fi−1f_{i-1}fi−1​。

回来看还有一个限制，就是每个集合不相同，只可能是前 i−1i-1i−1 个中的一个和第 iii 个集合相同。这样子剩下的 i−2i-2i−2 个集合一定满足所有限制，也就是有 fi−2f_{i-2}fi−2​ 个，相同的集合从 i−1i-1i−1 里选，有 2n−1−(i−2)2^n-1-(i-2)2n−1−(i−2) 中可能的取值。

把上面合起来，就是 fi=A2n−1i−1−fi−1−fi−2×(i−1)×(2n−1−(i−2))f_i=A_{2^n-1}^{i-1}-f_{i-1}-f_{i-2}\times (i-1)\times (2^n-1-(i-2))fi​=A2n−1i−1​−fi−1​−fi−2​×(i−1)×(2n−1−(i−2))。

复杂度 O(n+m)O(n+m)O(n+m)。

    x*=f;
}

const int mod=1e8+7;
int power(int x,int y=mod-2) {
	int sum=1;
	while (y) {
		if (y&1) sum=sum*x%mod;
		x=x*x%mod;y>>=1;
	}
	return sum;
}
int A[maxn],f[maxn],pw[maxn];
int n,m;
signed main(void){
	int i;
	read(n);read(m);
	for (pw[0]=1,i=1;i<=n;i++) pw[i]=pw[i-1]*2%mod;
	int res=pw[n]-1;
	for (A[0]=1,i=1;i<=m;i++) A[i]=A[i-1]*(res-i+1)%mod;
	f[0]=1;
	for (i=1;i<=m;i++) {
		f[i]=(A[i-1]-f[i-1]-f[i-2]*(i-1)%mod*(pw[n]-i+1+mod)%mod+mod*2)%mod;
	}
	int tmp=1;for (i=1;i<=m;i++) tmp=tmp*i%mod;
	printf("%lld",f[m]*power(tmp)%mod);
	return 0;
}
