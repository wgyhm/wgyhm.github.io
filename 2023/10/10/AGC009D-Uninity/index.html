AGC009D Uninity

Description

给定一棵树，求点分树的最小层数。

n≤105n\le 10^5n≤105

Solution

令 xxx 在点分树上的深度为 dxd_xdx​。

原树上的两个点，如果 x,yx,yx,y 满足 dx=dyd_x=d_ydx​=dy​，则一定满足 x→yx\to yx→y 的路径上有一个点 z,dz>dxz,d_z>d_xz,dz​>dx​。

令 fx,if_{x,i}fx,i​ 表示是否存在 xxx 与深度为 iii 的点之间没有一个 >i>i>i 的点。

然后贪心选择可以选的最小的。注意如果 xxx 的两个子树 u,vu,vu,v，有 fu,i=fv,i=1f_{u,i}=f_{v,i}=1fu,i​=fv,i​=1，那么如果 dx≤id_x\le idx​≤i，则连接 u,vu,vu,v 后会不合法。

复杂度 O(nlog⁡n)O(n\log n)O(nlogn)，但似乎可以做到 O(n)O(n)O(n)。

int power(int x,int y=mod-2) {
	int sum=1;
	while (y) {
		if (y&1) sum=sum*x%mod;
		x=x*x%mod;y>>=1;
	}
	return sum;
}
int g[maxn][21],f[maxn],n,nums[21],ans;
vector<int>to[maxn];
void dfs(int x,int pre) {
	int i,j;
	for (auto y:to[x]) if (y^pre) {
		dfs(y,x);
	}
	for (i=0;i<=20;i++) nums[i]=0;
	for (auto y:to[x]) if (y^pre) {
		for (i=0;i<=20;i++) if (g[y][i]) nums[i]++;
	}
	int fl=0;
	for (i=20;i>=0;i--) {
		if (nums[i]==0) fl=i;
		else if (nums[i]>1) break;
	}
	ans=max(ans,fl);nums[fl]=1;
	for (i=fl;i<=20;i++) if (nums[i]) g[x][i]=1;
}
