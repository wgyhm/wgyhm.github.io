T1

Description

图片暂缺 · image-20231013085603886

n≤105n\le 10^5n≤105 1s。

Solution

感觉 T1 是最有石粒的一题。

显然可以 O(nlog⁡n)O(n\log n)O(nlogn) 模拟哪些东西最早撞到。

观察到碰撞顺序不影响答案，用单调栈维护一个速度不降的序列。最后看下里面还有几个就好了。

复杂度 O(n)O(n)O(n) 。

	a[x].v=(a[x].v*a[x].m+a[y].v*a[y].m)/(a[x].m+a[y].m);
	a[x].m=a[x].m+a[y].m;

T2

Description

https://www.luogu.com.cn/problem/CF1374F

Solution

发现如果直接模拟冒泡排序，顺序不顺序的都没什么关系，最后可以做成除了最后两个不一定有序以外，其余都有序。

部分分提示我们要利用好有两个数相同的情况。

考虑一种第一次排完序以后的情况，然后依次操作：

3 3 5 7 6
3 7 3 5 6 // 然后把 7 移到两个 3 中间
3 3 7 5 6
3 3 6 7 5
3 3 5 6 7

感觉正确性在于如果随便这样换逆序对是 −2-2−2 的，但是遇到两个相同的就可以做到逆序对 −1-1−1。没怎么仔细证明。

具体的就把倒数第二个移到相同的后一个数的后面的后面。

注意特判最后 an=an−2a_n=a_{n-2}an​=an−2​ 的情况，这种也是可以的。

czh 写了随机化，正确率挺高的大概也在于只和奇偶有关，正确率差不多就 12\dfrac{1}{2}21​ 左右。

		}
	}
}

		if (now==id+4) calc(id+3),calc(id+3),now--;
		else calc(now-2),now-=2;
	}

	calc(id);
	solve(id);
	if (a[n]>=a[n-1]) {
		for (printf("%d\n",cnt),i=1;i<=cnt;i++) printf("%d ",ans[i]);
		return 0;
	}

T4

Description

https://www.luogu.com.cn/problem/CF1773G

模拟赛中是对 998244353998244353998244353 取模。

Solution

赛时我是计算方案数最后除以 n!n!n! 的，赛后感觉这样太蠢了。可能也是没调出来的一个原因。

观察到 m=17m=17m=17，很自然的想到枚举子集转移。

令 fSf_SfS​ 表示到剩下集合 SSS 的选手的概率。

如果有转移到 SSS 的子集，一定是 S∩si≠S,S∩si≠∅S\cap s_i\not = S,S\cap s_i\not = \varnothingS∩si​=S,S∩si​=∅。如果有这样的集合 sis_isi​，之前一定不会被用过来到达状态 SSS（如果用过，那么应该转移到 SSS 的子集），令 ccc 为存在这样的 sis_isi​ 的数量，所以可以放心转移：fS∩si←fScf_{S\cap s_i}\gets \dfrac{f_{S}}{c}fS∩si​​←cfS​​。这样复杂度是 O(n2m)O(n2^m)O(n2m) 的，平凡。

考虑怎么对于每个 SSS 快速计算 S∩si=TS\cap s_i=TS∩si​=T 的数量。

定义 gS,T=∑[S∩si=T]g_{S,T}=\sum [S\cap s_i=T]gS,T​=∑[S∩si​=T]。根据 sis_isi​ 是否包含 SSS 中不存在的一个点 {p}\{p\}{p}，有转移：gS,T=gS∪{p},T∪{p}+gS∪{p},Tg_{S,T}=g_{S\cup\{p\},T\cup\{p\}}+g_{S\cup\{p\},T}gS,T​=gS∪{p},T∪{p}​+gS∪{p},T​。复杂度 O(3m)O(3^m)O(3m)。

总复杂度为 O(nm+3m)O(nm+3^m)O(nm+3m)。

在具体写法上，T⊆ST\subseteq ST⊆S，所以可以用一个三进制数来描述 S,TS,TS,T，而不是很蠢的开 2m2^m2m 个 vector。
