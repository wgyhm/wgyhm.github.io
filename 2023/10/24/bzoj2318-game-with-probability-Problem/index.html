Solution

感觉题解说的都不是很明白，都是建立在他们同时选 p,qp,qp,q 或者同时选 1−p,1−q1-p,1-q1−p,1−q 上的。

前面都和题解区一样，令 p′,q′p',q'p′,q′ 表示他们抛硬币向上的概率，并不是题目中的 p,qp,qp,q。fi,gif_i,g_ifi​,gi​ 表示第 iii 轮 A,BA,BA,B 分别先手，AAA 的胜率。有转移：

fi=p′gi−1+q′(1−p′)fi−11−(1−p′)(1−q′)f_i=\dfrac{p'g_{i-1}+q'(1-p')f_{i-1}}{1-(1-p')(1-q')}fi​=1−(1−p′)(1−q′)p′gi−1​+q′(1−p′)fi−1​​

gig_igi​ 同理。

如果 fi−1<gi−1f_{i-1}<g_{i-1}fi−1​<gi−1​，自然的 A 要取，转移到 gi−1g_{i-1}gi−1​。这时候对于 B 的胜率 1−fi−1>1−gi−11-f_{i-1}>1-g_{i-1}1−fi−1​>1−gi−1​，所以 B 也想取。此时两者都是取的概率 p,qp,qp,q。

反之为 1−p,1−q1-p,1-q1−p,1−q。

观察到这种简单博弈在很多轮以后都不太会变。精度要求比较低的时候做到 100010001000 左右即可。

const int mod=1e9+7;
int power(int x,int y=mod-2) {
	int sum=1;
	while (y) {
		if (y&1) sum=sum*x%mod;
		x=x*x%mod;y>>=1;
	}
	return sum;
}
int n;
double f[1005][2];
double p,q;
void solve(void) {
	int i;
	scanf("%d%lf%lf",&n,&p,&q);
	f[0][0]=0;f[0][1]=1;n=min(n,1000);
	for (i=1;i<=n;i++) {
		double a=p,b=q;
		if (f[i-1][1]<f[i-1][0]) a=1-a,b=1-b; 
		f[i][0]=(a*f[i-1][1]+f[i-1][0]*(1-a)*b)/(1-(1-a)*(1-b));
		f[i][1]=(b*f[i-1][0]+f[i-1][1]*(1-b)*a)/(1-(1-a)*(1-b));
//		gdb(i,f[i][0],f[i][1]);
	}
	printf("%.6lf\n",f[n][0]);
}
signed main(void){
	int T
	read(T);
	while (T--) solve();
	return 0;
}
