Solution

考虑一个排列紧密的布阵方案，令长度为 kkk ，把其 L−kL-kL−k 的盒子中，插入 nnn 个板，方案为 (L−k+nn)\dbinom{L-k+n}{n}(nL−k+n​)。

现在要 dp 出所有的长度为 kkk 的紧密排列的方案数。发现是很典的插入dp。但是这样写的话需要维护左右端点是否被选，细节很多。讲一下从指导那里学来的做法。

同样是从大到小选，令 fi,j,kf_{i,j,k}fi,j,k​ 表示选了前 iii 个大的魔法师，预留了 jjj 个位置，占了 kkk 个格子。答案就是 fn,0,kf_{n,0,k}fn,0,k​。讨论第 iii 个魔法师旁边预留 0/1/2 个位置。

  • 预留 000 个位置，fi,j,k←fi−1,j+1,k×(j+1)f_{i,j,k}\gets f_{i-1,j+1,k}\times (j+1)fi,j,k​←fi−1,j+1,k​×(j+1)
  • 预留 111 个位置，还要选择预留是左边还是右边的位置，fi,j,k←fi−1,j,k−di×2jf_{i,j,k}\gets f_{i-1,j,k-d_i}\times 2jfi,j,k​←fi−1,j,k−di​​×2j。
  • 预留 222 个位置，fi,j,k←fi−1,j−1,k−2di×(j−1)f_{i,j,k}\gets f_{i-1,j-1,k-2d_i}\times (j-1)fi,j,k​←fi−1,j−1,k−2di​​×(j−1)。

其实和插入dp差不多，就是把维护段变成维护预留的位置。但是更好写。不用特判最左边和最右边端点的情况。

const int mod=1e9+7;
int power(int x,int y=mod-2) {
	int sum=1;
	while (y) {
		if (y&1) sum=sum*x%mod;
		x=x*x%mod;y>>=1;
	}
	return sum;
}
int f[maxn][maxn][maxn*maxn];
int d[maxn],n,m,ans;
bool cmp(int x,int y) {return x>y;}
int suf[1000005],isuf[1000005];
int C(int x,int y) {return suf[x]*isuf[y]%mod*isuf[x-y]%mod;}

	for (isuf[m]=power(suf[m]),i=m;i>=1;i--) isuf[i-1]=isuf[i]*i%mod;
	f[0][1][1]=1;
	int cnt=min(40*(40ll),m);

				add(f[i][j][k],(j+1)*f[i-1][j+1][k]);

				if (j>=1&&k>=2*d[i]) add(f[i][j][k],(j-1)*f[i-1][j-1][k-2*d[i]]);
			}
