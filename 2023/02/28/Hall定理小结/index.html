Hall 定理

对于二分图 G=(V,E)G=(V,E)G=(V,E) ，令 N(v)N(v)N(v) 表示与点 vvv 相邻的点集，则关于最大匹配，我们有如下结论：

设二分图 GGG 的两部分 X,YX,YX,Y，且 ∣X∣≤∣Y∣|X|\le |Y|∣X∣≤∣Y∣ ，则 ∣X∣|X|∣X∣ 存在完美匹配（存在一个大小为 ∣X∣|X|∣X∣ 的匹配）当且仅当 ∀S⊆X\forall S\subseteq X∀S⊆X，都有 S≤∣N(S)∣S\le |N(S)|S≤∣N(S)∣。

推论1

如果一个无向图的每个点度数都为 kkk，则成为其为 kkk 正则图。

那么左右点数相等的 kkk 正则二分图必有完美匹配。k≥1k\ge 1k≥1

证明：

若不然，考虑一个左部点集 LLL，则存在 R=N(L),∣R∣<∣L∣R=N(L),|R|<|L|R=N(L),∣R∣<∣L∣。考虑到 ∣R∣|R|∣R∣ 的所有点的度数和不小于 ∣L∣×k|L|\times k∣L∣×k ，但是 ∣R∣<∣L∣|R|<|L|∣R∣<∣L∣，这与每个点的度数都为 kkk 矛盾。

推论2

Hall 定理可以用于点有权值的情况。左部点 iii 需要匹配 aia_iai​ 个右部点，右部点 iii 需要匹配 bib_ibi​ 个左部点。**匹配是可重复的。**只需要将定理改写一下。其有完美匹配的充要条件为：

∀S⊆X,∣∑x∈Sax∣≤∣∑y∈N(S)by∣\forall S\subseteq X,|\sum\limits_{x\in S}a_x|\le |\sum\limits_{y\in N(S)}b_y|∀S⊆X,∣x∈S∑​ax​∣≤∣y∈N(S)∑​by​∣

证明可以将左部点 iii 拆成 aia_iai​ 个点，右部点同样。发现此条件和原本的 Hall 定理是等价的。

CF1373F Network Coverage

题意：

nnn 个城市，这 nnn个城市首尾相接形成一个环。每个城市需要 aia_iai​ 个网络数量。nnn 个网络基站，第 iii 个网络基站有 bib_ibi​ 的网络数量，可以给 iii 和 i+1i+1i+1 提供 网络。（第 nnn 个网络基站可以给第 nnn 座城市和第 111 座城市提供网络）。

判断能否使得所有的家庭都获得网络。

n≤106n\le 10^6n≤106

做法

显然是个带权二分图求完美匹配的题。

考虑枚举城市的集合 LLL，如果 LLL 不是一个连续的区间，判断其是否合法，与其中每个连续的区间分别同时满足判定的条件是等价的。

转化为对于任意区间 [l,r][l,r][l,r] ，∑i=lrai≤∑i=l−1rbi\sum\limits_{i=l}^r a_i\le \sum\limits_{i=l-1}^rb_ii=l∑r​ai​≤i=l−1∑r​bi​ 都成立。

前缀和+后缀最大值即可。题目要求为环的情况，断环为链。

CODE
int a[maxn],b[maxn],n,d[maxn],suf[maxn];
inline int solve(void) {
	int i,sum1=0,sum2=0;

	for (i=1;i<=n;i++) {
		if (suf[i+1]-d[i]+b[i]<0) return puts("NO");
	}
	return puts("YES");
}

题意

考虑按 lil_ili​ 升序排序。 当前枚举到 iii。必须去 iii ，则：

namespace Seg{
	struct yyy{
		int Max,lazy;
	}f[maxn<<2];
	inline void Pushup(int rt) {f[rt].Max=max(f[rt<<1].Max,f[rt<<1|1].Max);}
	inline void Pushdown(int l,int r,int rt) {
		if (f[rt].lazy) {
			int mid=l+r>>1,k=f[rt].lazy;f[rt].lazy=0;
			f[rt<<1].Max+=k,f[rt<<1|1].Max+=k;
			f[rt<<1].lazy+=k,f[rt<<1|1].lazy+=k;
		}
	}
	inline void Update(int l,int r,int rt,int head,int tail,int k) {
		if (head<=l&&r<=tail) return f[rt].Max+=k,f[rt].lazy+=k,void();
		int mid=l+r>>1;Pushdown(l,r,rt);
		if (head<=mid) Update(l,mid,rt<<1,head,tail,k);
		if (tail>mid)  Update(mid+1,r,rt<<1|1,head,tail,k);
		Pushup(rt); 
	}
	inline int Query(int l,int r,int rt,int head,int tail) {
		if (head<=l&&r<=tail) return f[rt].Max;
		int mid=l+r>>1,tmp1=0,tmp2=0;Pushdown(l,r,rt);
		if (head<=mid) tmp1=Query(l,mid,rt<<1,head,tail);
		if (tail>mid)  tmp2=Query(mid+1,r,rt<<1|1,head,tail);
		return max(tmp1,tmp2);
	}
}

using Seg::Query;

	for (i=0;i<=m;i++) Update(0,m,1,i,i,i);
	for (i=1;i<=n;i++) {
		Update(0,m,1,0,g[i].r,1);
		ans=max(ans,Query(0,m,1,g[i].l,m)-g[i].l);
	}
	printf("%d",max(max(0,n-m+1),ans-m));
	return 0;
}

题意

AAA 的长度为 nnn，BBB 的长度为 mmm。

求 AAA 有多少长度为 mmm 的区间中的数和 BBB 中的数完美匹配。

两个数匹配当且仅当其和不小于 hhh。 (区间必须连续)

n,m≤1.5×105n,m\le 1.5\times 10^5n,m≤1.5×105

解法

顺序与连边无关。考虑将 BBB 先从大到小排序。那么对于 aia_iai​ ，其向 BBB 连边的节点一定为区间 [1,li][1,l_i][1,li​] 。这是容易计算的。

考虑 Hall 定理。枚举 N(S)=[1,j]N(S)=[1,j]N(S)=[1,j]，则有：

最大匹配=∣X∣−max⁡S⊆X(∣S∣−∣N(S)∣)=∣X∣−max⁡S⊆X(∑1[li≤j]−j)\text{最大匹配}=|X|-\max_{S\subseteq X}(|S|-|N(S)|)=|X|-\max_{S\subseteq X}(\sum\limits 1[l_i\le j]-j)最大匹配=∣X∣−S⊆Xmax​(∣S∣−∣N(S)∣)=∣X∣−S⊆Xmax​(∑1[li​≤j]−j)

线段树维护 lil_ili​ 即可。
