CF1670F Jee, You See?

Description

给定 4 个整数 n,l,r,zn,l,r,zn,l,r,z 1≤n≤1000,1≤l≤r≤1018,1≤z≤10181 \le n \le 1000,1 \le l \le r \le 10^{18},1 \le z \le 10^{18}1≤n≤1000,1≤l≤r≤1018,1≤z≤1018

求满足一下条件的序列 aaa 的个数：

  1. aia_iai​ 为非负整数
  2. l≤a1+a2+…an≤rl \le a_1 + a_2 + \dots a_n \le r l≤a1​+a2​+…an​≤r
  3. a1⊕a2⊕⋯⊕an=za_1 \oplus a_2 \oplus \dots \oplus a_n = za1​⊕a2​⊕⋯⊕an​=z

其中 ⊕\oplus⊕ 表示二进制按位异或运算

2s 250MB

Solution

令 ∑ai≤r\sum a_i\le r∑ai​≤r 且符合题意的个数为 G(r)G(r)G(r) ，则答案为 G(r)−G(l−1)G(r)-G(l-1)G(r)−G(l−1)。转化为求 1≤∑ai≤r1\le \sum a_i\le r1≤∑ai​≤r 的个数。

考虑数位 dp ，令 f[i][j]f[i][j]f[i][j] 表示从低到高第 iii 位，还能以 2i×j2^i\times j2i×j 填剩下的位数。

令 x=2j+[n第 i 位为1]x=2j+\text{[n第 i 位为1]}x=2j+[n第 i 位为1]，转移是 f[i][x−t]⇐f[i+1][j](nt)f[i][x-t]\Leftarrow f[i+1][j]\dbinom{n}{t}f[i][x−t]⇐f[i+1][j](tn​)

考虑到从低到高第 iii 位之和最大只有 (2i−1)n(2^i-1)n(2i−1)n，所以第二位最大只有 nnn。
