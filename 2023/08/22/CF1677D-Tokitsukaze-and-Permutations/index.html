Tokitsukaze and Permutations

Description

有一个长度为 nnn 的数组 ppp，将执行 kkk 次操作。

操作过程：对于 [1,n][1,n][1,n] 中，当pi>pi+1 p_{i} > p_{i+1}pi​>pi+1​，则交换 pi,pi+1p_{i},p_{i+1}pi​,pi+1​。

经过 kkk 次操作之后，得到了一个新数组 aaa，再定义数组 vvv 表示在 [1,i−1][1,i-1][1,i−1] 中比 aia_{i}ai​ 大的个数。

现在给定 vvv，但是有可能其中的值为 −1-1−1，这表示它的值并不确定 。

求有多少种 ppp 满足在 kkk 次操作后得到的 vvv 和给定确定值一致，结果取模 998244353998244353998244353。

1≤n≤1061\le n\le 10^61≤n≤106 2s 250MB

Solution

大为震撼。

首先有一个结论 ：

  • 一个排列 ppp 对应唯一的 vvv。

如果一个 vvv 是合法的，当且仅当 vi∈[0,i−1]v_i\in [0,i-1]vi​∈[0,i−1]。

再考虑每次操作的本质，把 viv_ivi​ 整体向左移一位，高位补 000，其他位置 vi←max⁡(vi−1,0)v_i\gets \max(v_i-1,0)vi​←max(vi​−1,0)。

所以操作 kkk 次以后，末尾 kkk 个数为 000，如果不是就输出 000。

对于 i∈[1,n−k]i\in [1,n-k]i∈[1,n−k] 中，考虑对答案的贡献：

  • 如果 viv_ivi​ 为 −1-1−1 ，操作 kkk 次之前 vi+kv_{i+k}vi+k​ 也是不知道的，可以取 [0,i+k−1][0,i+k-1][0,i+k−1]。
  • 如果 viv_ivi​ 为 000，操作 kkk 次之前 vi+k∈[0,k]v_{i+k}\in[0,k]vi+k​∈[0,k]。
  • 如果 vi>0v_i>0vi​>0，操作 kkk 次之前 vi+k=vi+kv_{i+k}=v_i+kvi+k​=vi​+k。是确定的。

所有贡献乘起来即可。

Code

int n,v[maxn],p[maxn],k;
inline void solve(void) {
	int i,ans=1;
	read(n);read(k);
	for (i=1;i<=n;i++) read(v[i]);
	for (i=n;i>n-k;i--) if (v[i]>0) return puts("0"),void();
	for (i=n;i>k;i--) 
		if (v[i-k]==-1) ans=ans*i%mod;
		else if (v[i-k]==0) ans=ans*(k+1)%mod;
	for (i=1;i<=k;i++) ans=ans*i%mod;
	printf("%lld\n",ans);
}
signed main(void){
	int T;
	read(T);
	while (T--) solve();
	return 0;
}
