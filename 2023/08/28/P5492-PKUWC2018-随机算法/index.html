P5492 [PKUWC2018] 随机算法

Description

https://www.luogu.com.cn/problem/P5492

Solution

令 fs,jf_{s,j}fs,j​ 表示点集为 sss，独立集为 jjj 的方案数。

考虑刷表，令加入一个点 xxx，且一定不在当前的点集 sss 之中。xxx 相邻且不在点集 sss 的点，这些可以在 xxx 选过以后随意选。

令 gsg_sgs​ 表示点集 sss 中点的个数，toxto_xtox​ 表示与 xxx 相邻的点构成的点集。

有转移：

f[0][0]=1;
	for (s=0;s<N;s++) {
		for (i=0;i<n;i++) if (((s>>i)&1)==0) {
			for (j=0;j<=g[s];j++) {
				add(f[s|(1<<i)|to[i]][j+1],1ll*f[s][j]*suf[n-g[s]-1]%mod*isuf[n-g[s]-1-g[to[i]-(to[i]&s)]]%mod);
			}	
		} 
	}

复杂度是 O(2nn2)O(2^nn^2)O(2nn2) ，需要卡卡常。

事实上，一个最大独立集只会从最大独立集转移过来。所以先求出点集 sss 的最大独立集 sizssiz_ssizs​。再进行转移，这样只需要记录 fsf_sfs​ 表示点集 sss 构成的最大独立集的方案数。
