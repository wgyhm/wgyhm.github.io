模拟赛原题。

似乎有更简单的做法。反正我的做法就是先从小到大枚举一下当前是第几个数，设为 kkk，然后连续且都等于 kkk 的块合并。如果是偶数，那么这个对左边和右边都有贡献。如果是奇数，作为分割点。每次递归（分治？）的时候记录左边和右边有几个等于 kkk 的。

然后只有一个块之类的特判一下？

int n,a[maxn],rt[maxn];
struct node{
	int l,r;
	node(int a=0,int b=0) {l=a;r=b;}
};
inline int solve(int deep,int l,int r,int numl,int numr) {
	if (l>r) return 0;
	assert(deep<=40);
//	gdb(deep,l,r,numl,numr);
//	if (l==r) return a[l]+(int)log2(numr+numl+1); 
	int i,tot=1,ans=0,tmp,j;
	vector<node>g;
	g.push_back(node(0,0));
	g.push_back(node(l-numl,l-1));
//	g[1].l=l-numl,g[1].r=l-1;
	for (i=l;i<=r;i++) {
		if (a[i]==deep) {
			if (g[tot].r==i-1) g[tot].r++;
			else ++tot,g.push_back(node(i,i));//g[tot].l=g[tot].r=i;
		}
	}
	if (g[tot].r==r) g[tot].r+=numr;
	else ++tot,g.push_back(node(r+1,r+numr));//g[tot].l=r+1,g[tot].r=r+numr;
	if (tot==1) return deep+(int)(log2(g[1].r-g[1].l+1));
	int las=1;
	for (i=2;i<=tot;i++) {
		if (i!=tot&&(g[i].r-g[i].l+1)%2==0) continue;
		int cnt=g[las].r;
		for (j=g[las].r+1;j<=g[i].l-1;j++) {
			if (a[j]==deep&&rt[cnt]==deep) rt[cnt]=deep+1;
			else rt[++cnt]=a[j];
		}
		for (j=g[las].r+1;j<=cnt;j++) a[j]=rt[j];
		int tmp=solve(deep+1,g[las].r+1,cnt,(g[las].r-g[las].l+1)/2,(g[i].r-g[i].l+1)/2);
		ans=max(ans,tmp);las=i;
	}
	return ans; 
}

	printf("%d",solve(1,1,n,0,0));
	return 0;
}

CF1710C XOR Triangle

对于 x,y,zx,y,zx,y,z 上同一位的 a,b,ca,b,ca,b,c ，我们发现 a⨁b+b⨁c≥a⨁ca\bigoplus b+b\bigoplus c \ge a\bigoplus ca⨁b+b⨁c≥a⨁c，所以只要满足 a⨁b+b⨁c>a⨁ca\bigoplus b+b\bigoplus c > a\bigoplus ca⨁b+b⨁c>a⨁c ，即可保证 x⨁y+y⨁z>x⨁zx\bigoplus y+y\bigoplus z > x\bigoplus zx⨁y+y⨁z>x⨁z 。

显然这个式子是轮换的，所以说当且仅当满足三个条件的数可以被记录答案。

因为是二进制下的数，所以如果没有记忆化是否达到上界多出来的常数是不可忽略的。就多开三维分别记录一下。

CF55D Beautiful numbers

由 111 到 999 之中任意选取数的 lcm\text{lcm}lcm 只有 484848 个，记为 ppp ，尝试枚举。

记录当前在第几位，当前每位的 lcm\text{lcm}lcm ，当前数模 ppp 的值，是否达到上界。

复杂度是 48×18×48×2520×T×248\times 18 \times 48\times 2520\times T\times 248×18×48×2520×T×2 ，还不包括上界带来的常数，所以是不可接受的。

考虑去除枚举。记录当前在第几位，当前每位的 lcm\text{lcm}lcm ，当前数模 252025202520 的值，是否达到上界。

只要判断模 252025202520 的值是否能被每位的 lcm\text{lcm}lcm 整除即可。

然后发现如果每次都初始化会 TLE。

多出来的时间复杂度不仅仅在初始化上，更在于每次都需要重新计算。

因为我的写法把最高位设为 111 ，因为不同数位数不一样，所以 111 所代表当前第几位也就不一样，不初始化就会 WA。解决这个问题，只需要将 第一位设为个位，然后记忆化搜索的时候从高位到低位即可。
