〇、前言

本来最近一段时间是想搞网络流的。结果最近几天老师要讲斜率优化，加上之前想学但是没看懂，就有了这篇学习笔记。

感谢 这篇博客 让我看懂了斜率优化。

一、基本概念

目前我所了解的，斜率优化是用来优化 dpdpdp，形如：

fi=min⁡/max⁡{fj+Ai×Bj+Cj+Di}f_i=\min / \max\{f_j+A_i\times B_j+C_j+D_i\}fi​=min/max{fj​+Ai​×Bj​+Cj​+Di​}

看起来与单调队列的：

fi=min⁡/max⁡{fj+Ai+Bj}f_i=\min/\max\{f_j+A_i+B_j\}fi​=min/max{fj​+Ai​+Bj​}

有点类似，因为斜率优化正是利用单调队列来实现的。

不过这不重要。重要的是理解思想。

二、算法介绍

首先看一道经典例题：

P3195 [HNOI2008]玩具装箱

设 fif_ifi​ 为以 iii 结尾的最小总费用。不难想到 n2n^2n2 的 dpdpdp 转移方程，如果想不到的话建议巩固 dpdpdp 基础：

fi=min⁡0≤j<i{fj+(sumi+i−sumj−j−L−1)2}f_i=\min\limits_{0\le j<i}\{f_j+(sum_i+i-sum_j-j-L-1)^2\}fi​=0≤j<imin​{fj​+(sumi​+i−sumj​−j−L−1)2}

将与 iii 相关的放在一起，与 jjj 相关和常数项的放在一起。事实上，常数项也可以和 iii 相关的放在一起。

令 A=sumi+i,B=sumj+j+L+1A=sum_i+i,B=sum_j+j+L+1A=sumi​+i,B=sumj​+j+L+1，则原式化简为：

fi=min⁡0≤j<i{fj+(A−B)2}=min⁡0≤j<i{fj+A2−2AB+B2}f_i=\min\limits_{0\le j<i}\{f_j+(A-B)^2\}=\min\limits_{0\le j<i}\{f_j+A^2-2AB+B^2\}fi​=0≤j<imin​{fj​+(A−B)2}=0≤j<imin​{fj​+A2−2AB+B2}

为了方便，把 min⁡\minmin 去了，然后把与只 jjj 相关的项扔到等式右边，其他在左边：

2A×B+fi−A2=fj+B22A\times B+f_i-A^2=f_j+B^22A×B+fi​−A2=fj​+B2 2A⏟k×B⏟x+fi−A2⏟b=fj+B2⏟y\begin{matrix}\underbrace{2A}\\k\end{matrix}\times \begin{matrix}\underbrace{B}\\x\end{matrix}+\begin{matrix}\underbrace{f_i-A^2}\\b\end{matrix}=\begin{matrix}\underbrace{f_j+B^2}\\y\end{matrix}2A​k​×B​x​+fi​−A2​b​=fj​+B2​y​

问题转化成了：我们可以将经过许多点 Pj(Bj,fj+Bj2)P_j(B_j,f_j+B_j^2)Pj​(Bj​,fj​+Bj2​) ，斜率为 2A2A2A 的直线，所得的最小截距(fi−A2)(f_i-A^2)(fi​−A2)的点为最佳转移点。

如何求这最佳转移点呢，还是要对于每次转移，O(n)O(n)O(n) 的时间扫一遍吗？

我们先看一个问题，如下图，对于经过两个点 N(a1,b1),M(a2,b2)N(a_1,b_1),M(a_2,b_2)N(a1​,b1​),M(a2​,b2​) ，a1<a2a_1<a_2a1​<a2​，斜率都为 kkk 的直线，什么时候经过 NNN 的截距小呢？什么时候经过 MMM 点的截距小呢？

图片暂缺

考虑先写出直线方程 ：

对于 NNN点 ，y−b1=k(x−a1)y-b_1=k(x-a_1)y−b1​=k(x−a1​) ，化简得 截距B1=b1−k⋅a1B_1=b_1-k\cdot a_1B1​=b1​−k⋅a1​

对于 MMM点，y−b2=k(x−a2)y-b_2=k(x-a_2)y−b2​=k(x−a2​) ，化简得 截距B2=b2−k⋅a2B_2=b_2-k\cdot a_2B2​=b2​−k⋅a2​

如果 NNN 点截距小，则 B1<B2B_1<B_2B1​<B2​ 解得 k<b1−b2a1−a2k<\dfrac{b_1-b_2}{a_1-a_2}k<a1​−a2​b1​−b2​​

如果 MMM 点截距小，则 B1>B2B_1>B_2B1​>B2​ 解得 k>b1−b2a1−a2k>\dfrac{b_1-b_2}{a_1-a_2}k>a1​−a2​b1​−b2​​

回到原题，我们发现 A=sumi+iA=sum_i+iA=sumi​+i 是单调递增的。也就是说，斜率 kkk 随着转移点 iii 的增大而增大。

对于斜率 kkk 不单调递增的情况下，我们后文会接着讨论。

对于两个点 Pj(aj,bj)P_j(a_j,b_j)Pj​(aj​,bj​) 和 Pk(ak,bk)P_k(a_k,b_k)Pk​(ak​,bk​) ，aj<aka_j<a_kaj​<ak​ ，如果此时 k<bj−bkaj−akk<\dfrac{b_j-b_k}{a_j-a_k}k<aj​−ak​bj​−bk​​ ，那么转移 jjj 点，反之转移 kkk 点，而且之后再也不会转移到 jjj 点。类似一个弹出操作。你可能会想到用一个数据结构维护这个弹出操作，是什么呢？

正是我们前文讲到的单调队列！

巧的是，每个转换而来的点 Pj(Bj,fj+Bj2)P_j(B_j,f_j+B_j^2)Pj​(Bj​,fj​+Bj2​) ，其中 BjB_jBj​ 也都是递增的，这表明着可以将点 PjP_jPj​ 插入队尾而不需要插入中间的某一位置。

对于 BjB_jBj​ 不单调递增的情况下，我们后文会接着讨论。而且现在我也没有遇到过。

现在，已经转移好了 iii 点，可是如何将 iii 点从队尾加入了这单调队列，转移其他的点呢？

如下图，假设我们现在又有三个点，分别是 P1(a1,b1),P2(a2,b2)P_1(a_1,b_1),P_2(a_2,b_2)P1​(a1​,b1​),P2​(a2​,b2​) 和我们将要加入的点 P3(a3,b3)P_3(a_3,b_3)P3​(a3​,b3​)，其中 a1<a2<a3a_1<a_2<a_3a1​<a2​<a3​。

为了方便叙述，我们定义 k1=b1−b2a1−a2,k2=b2−b3a2−a3,k3=b1−b3a1−a3k_1=\dfrac{b_1-b_2}{a_1-a_2},k_2=\dfrac{b_2-b_3}{a_2-a_3},k_3=\dfrac{b_1-b_3}{a_1-a_3}k1​=a1​−a2​b1​−b2​​,k2​=a2​−a3​b2​−b3​​,k3​=a1​−a3​b1​−b3​​。

  1. 对于 k1<k2k_1<k_2k1​<k2​ 的情况

图片暂缺 对于斜率 kkk：

  • 如果使 P1P_1P1​ 截距最小，k<k1k<k_1k<k1​

  • 如果使 P2P_2P2​ 截距最小，k1≤k<k2k_1\le k<k_2k1​≤k<k2​

  • 如果使 P3P_3P3​ 截距最小，k2≤kk2\le kk2≤k

  1. 对于 k1>k2k_1>k_2k1​>k2​ 的情况

图片暂缺

对于斜率 kkk：

  • 如果使 P1P_1P1​ 截距最小，k<k3k<k_3k<k3​

  • 如果使 P2P_2P2​ 截距最小，无解，所以无论如何，最小截距也就是最优转移点，一定不是 P2P_2P2​。

  • 如果使 P3P_3P3​ 截距最小，k3≤kk3\le kk3≤k

所以，我们要在单调队列中维护斜率严格递增的一个点集，具体的，维护一个下凸包。这是取 min⁡\minmin 的情况。相同的，取 max⁡\maxmax 就得维护一个上凸包。

回顾一下整个流程：

  1. 如果队列前两个点的斜率小于 kkk，则踢出队首。
  2. 取队首作为转移点。
  3. 将转移点 iii 入队之前，维护一个斜率递增的单调队列。如果下降，则弹出队尾。

代码就很简单了。

Code:

#include<bits/stdc++.h>
#define maxn 100005
#define rg register
#define int long long 
#define ll long long
#define put() putchar('\n')
using namespace std;
inline void read(int &x){
	int f=1;x=0;char c=getchar();
	while (c<'0'||c>'9') {if (c=='-') f=-1;c=getchar();}
	while (c>='0'&&c<='9') {x=x*10+c-'0';c=getchar();}
	x*=f;
}
int n,l,head,tail,q[maxn];
int sum[maxn],A[maxn],B[maxn],a[maxn],f[maxn];
inline double X(int i){return B[i];}
inline double Y(int i){return f[i]+B[i]*B[i];}
inline double slope(int i,int j){return (Y(i)-Y(j))/(X(i)-X(j));}
signed main(){
//	freopen("1.in","r",stdin);
    rg int i;
    read(n);read(l);
    for (i=1;i<=n;i++) read(a[i]),sum[i]=sum[i-1]+a[i];
    for (i=0;i<=n;i++) A[i]=sum[i]+i,B[i]=sum[i]+i+l+1;
    head=tail=1;
    for (i=1;i<=n;i++){
    	while (head<tail&&2*A[i]>=slope(q[head],q[head+1])) head++;
        //弹出队首
    	f[i]=f[q[head]]+A[i]*A[i]-2*A[i]*B[q[head]]+B[q[head]]*B[q[head]];
        //Update
    	while (head<tail&&slope(q[tail-1],q[tail])>=slope(q[tail],i)) tail--;
        //维护上凸包
    	q[++tail]=i;
	}
	printf("%lld",f[n]);
	return 0;
}

三、例题讲解

P2365 任务安排

虽然可以用 O(n2)O(n^2)O(n2) 草过去，但是为了巩固斜率优化还是推荐大家再写一遍。

容易想到 n2dp:n^2 dp:n2dp:

fi=min⁡0≤j<ifj+s×(sumCn−sumCj)+sumTi×(sumCi−sumCj)f_i=\min\limits_{0\le j<i}{f_j+s\times(sumC_n-sumC_j)+sumT_i\times(sumC_i-sumC_j)}fi​=0≤j<imin​fj​+s×(sumCn​−sumCj​)+sumTi​×(sumCi​−sumCj​)

看到有 iii 和 jjj 的乘积，考虑斜率优化：

fi=fj+s×sumCn−s×sumCj+sumTi×sumCi−sumTi×sumCj)f_i={f_j+s\times sumC_n-s\times sumC_j+sumT_i\times sumC_i-sumT_i\times sumC_j)}fi​=fj​+s×sumCn​−s×sumCj​+sumTi​×sumCi​−sumTi​×sumCj​)

与 jjj 有关的扔到右边：

sumTi+s⏟k×sumCj⏟x+fi−sumTi×sumCi⏟b=fj+s×sumCn⏟y\begin{matrix}\underbrace{sumT_i+s}\\k\end{matrix}\times \begin{matrix}\underbrace{sumC_j}\\x\end{matrix}+\begin{matrix}\underbrace{f_i-sumT_i\times sumC_i}\\b\end{matrix}=\begin{matrix}\underbrace{f_j+s\times sumC_n}\\y\end{matrix}sumTi​+s​k​×sumCj​​x​+fi​−sumTi​×sumCi​​b​=fj​+s×sumCn​​y​

经过猜想+测试，以下整理也是可以的：

sumTi⏟k×sumCj⏟x+fi−sumTi×sumCi⏟b=fj+s×sumCn−s×sumCj⏟y\begin{matrix}\underbrace{sumT_i}\\k\end{matrix}\times \begin{matrix}\underbrace{sumC_j}\\x\end{matrix}+\begin{matrix}\underbrace{f_i-sumT_i\times sumC_i}\\b\end{matrix}=\begin{matrix}\underbrace{f_j+s\times sumC_n-s\times sumC_j}\\y\end{matrix}sumTi​​k​×sumCj​​x​+fi​−sumTi​×sumCi​​b​=fj​+s×sumCn​−s×sumCj​​y​

换言之，我们只需要把 i,ji,ji,j 相关的相乘的项作为斜率 kkk 。

Code:

#include<bits/stdc++.h>
#define maxn 100005
#define rg register
#define int long long 
#define ll long long
#define put() putchar('\n')
using namespace std;
inline void read(int &x){
	int f=1;x=0;char c=getchar();
	while (c<'0'||c>'9') {if (c=='-') f=-1;c=getchar();}
	while (c>='0'&&c<='9') {x=x*10+c-'0';c=getchar();}
	x*=f;
}
int n,head=1,tail=1,q[maxn];
int f[maxn],s,sumT[maxn],sumC[maxn],A[maxn],B[maxn];
inline double X(int i){return sumC[i];}
inline double Y(int i){return f[i]+s*(sumC[n]-sumC[i]);}
inline double slope(int i,int j){return (Y(i)-Y(j))/(X(i)-X(j));}//字面意思
signed main(){
	rg int i,x,y;
	read(n);read(s);
	for (i=1;i<=n;i++){
		read(x);read(y);
		sumT[i]=sumT[i-1]+x;
		sumC[i]=sumC[i-1]+y;
	}
    for (i=1;i<=n;i++){
    	while (head<tail&&sumT[i]+s>=slope(q[head],q[head+1])) head++;
        //将斜率<=k的弹出队列
    	f[i]=f[q[head]]+s*(sumC[n]-sumC[q[head]])+sumT[i]*sumC[i]-sumT[i]*sumC[q[head]];
        //Update
    	while (head<tail&&slope(q[tail-1],q[tail])>=slope(q[tail],i)) tail--;
        //维护上凸包
    	q[++tail]=i;
	}
	printf("%lld",f[n]);
	return 0;
}
