2. 算法概述

单纯形算法有两个基本的操作 —— 转轴操作（Pivot） 和 求解过程 (Simplex)。

Pivot

转轴操作是对于一组限制中一个基变量 xAx_AxA​ 和一个非基变量 xBx_BxB​ 代换的操作。

我们称 xAx_AxA​ 为换入变量，xBx_BxB​ 为换出变量。

具体的说：

xA=bi−∑j=1nai,jxjx_{A}=b_i-\sum\limits_{j=1}^n a_{i,j}x_jxA​=bi​−j=1∑n​ai,j​xj​

把 xBx_BxB​ 代换到等式左边，得：

xB=bi−xA−∑j=1,j≠Bnai,jxjai,Bx_B=\dfrac{b_i-x_A-\sum\limits_{j=1,j\not = B}^na_{i,j}x_j}{a_{i,B}}xB​=ai,B​bi​−xA​−j=1,j=B∑n​ai,j​xj​​

当然在选择的时候要确保 ai,B≠0a_{i,B}\not= 0ai,B​=0。

用这条等式代替原等式，然后将这条等式依次带入其他等式和要优化的结果。

Simplex

Simplex 就是单纯形算法的主过程，从一个基本解出发，经过一系列的转轴操作，达到最优解。通过选择特定的换入变量和换出变量，使每一次转轴操作都能使目标函数增大，直到达到全局最优解。

基本过程：

  • 选择一个满足 ce≥0c_e \ge 0ce​≥0 的非基变量 xex_exe​。
  • 找到那个满足 al,e>0a_{l,e} > 0al,e​>0 且 blal,e\dfrac{b_l}{a_{l,e}}al,e​bl​​ 最小的基变量 xn+lx_{n+l}xn+l​。
  • 执行 pivot(l,e)pivot(l,e)pivot(l,e) 然后回到第一步。

每次选择一个增大后可以使当前状态变优的变量，将其增加到有一个基变量变成 000 位置，然后互换他们的位置。

第二步取最小的目的是一个贪心优化，可以使 pivotpivotpivot 的次数降低许多。

该过程在一下两种情况下会终止：

  • 找不到一个合法的 eee ，显然现在已经找到了最优解。可以手模一组数据。
  • 找不到一个合法的 lll ，此时的最优解是 ∞\infty∞ 。

3. 初始化过程

前文提到了 SimplexSimplexSimplex 只能在 bi≥0b_i\ge 0bi​≥0 的时候进行。如果 bi<0b_i<0bi​<0 呢？这时候就要进行初始化。

具体的，初始化常见的有两种方法：新建一个辅助线性规划或者通过 pivotpivotpivot 进行初始化。本文只介绍后一种方法。

根据 pivotpivotpivot 的过程，在 ai,B>0a_{i,B}>0ai,B​>0 的情况下，bib_ibi​ 的正负性并不会被改变。所以当 bib_ibi​ 为负数时，只需要找到一个 ai,j<0a_{i,j}<0ai,j​<0 进行转轴操作即可改变 bib_ibi​ 的正负性。

当然，如果 bi<0b_i<0bi​<0 时，并没有找到 ai,j<0a_{i,j}<0ai,j​<0 ，此时整个线性规划无解。

int id[maxn*2];
double a[maxn][maxn],vv[maxn];
int n,m,op;
inline int dcmp(double x){
	if (x>eps) return 1;
	else if (x<-eps) return -1;
	else return 0;

namespace Semplex{
    inline void Pivot(int r,int c){
    	rg int i,j;double x=-a[r][c];
    	swap(id[n+r],id[c]);a[r][c]=-1;
		for (i=0;i<=n;i++) a[r][i]/=x;
    	for (i=0;i<=m;i++){
    		if (dcmp(a[i][c])&&i!=r){
    			x=a[i][c];a[i][c]=0;
    			for (j=0;j<=n;j++) a[i][j]+=x*a[r][j]; 
			}
		}
	}
	inline bool init(void){
		rg int x,y,i;
		for (i=1;i<=n;i++) id[i]=i;
		while (1){
			x=y=0;
			for (i=1;i<=m;i++) 
			    if (dcmp(a[i][0])<0&&(!x||rand()&1)) x=i;
			if (!x) return 1;
			for (i=1;i<=n;i++)
			    if (dcmp(a[x][i])>0&&(!y||rand()&1)) {y=i;break;}
			if (!y) {puts("Infeasible");return 0;}
			Pivot(x,y);
		}
    }
	inline void Semplex(void){
		rg int i,x,y,f;
		if (!init()) return;
		while (1){
			x=y=0;f=1;rg double w,t;
		    for (i=1;i<=n;i++) 
		        if (dcmp(a[0][i])>0&&(!x||rand()&1)) x=i;
		    if (!x) break;
		    for (i=1;i<=m;i++)
		        if (dcmp(a[i][x])<0&&(w=-a[i][0]/a[i][x],f||t>w)) y=i,f=0,t=w;
		    if (!y) {puts("Unbounded");return;}
		    Pivot(y,x);
		}
		printf("%.9lf\n",a[0][0]);
		if (!op) return;
		for (i=1;i<=n;i++) vv[i]=0;
		for (i=n+1;i<=n+m;i++) vv[id[i]]=a[i-n][0];
		for (i=1;i<=n;i++) printf("%.9lf ",vv[i]);
	}
}
