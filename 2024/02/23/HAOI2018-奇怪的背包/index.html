Solution

先观察部分分。n=1n=1n=1 是即为 gcd⁡(x,p)\gcd(x,p)gcd(x,p) 的倍数可以被表示。容易发现可以把体积 xxx 等价为 gcd⁡(x,p)\gcd(x,p)gcd(x,p)。

考虑一个物品集合 SSS 可以表示的重量集合为 gcd⁡(S1,S2,…,Sk,p)\gcd(S_1,S_2,\dots,S_k,p)gcd(S1​,S2​,…,Sk​,p) 的倍数。然后我们就有一个 dp 为 fi,jf_{i,j}fi,j​ 表示考虑到前 iii 个物品，能表示的选出最大公约数为 jjj 的集合数量。然后暴力转移是 O(np)O(np)O(np) 的。发现 jjj 有用的都是 ppp 的因数，所以优化到 O(nd(p))O(nd(p))O(nd(p))。又发现本质不同的物品只有 d(p)d(p)d(p) 个，xxx 个相同物品的转移系数为 2x−12^x-12x−1。

查询先预处理一个前缀和即可。复杂度为 O(q+d(p)2log⁡d(p))O(q+d(p)^2\log d(p))O(q+d(p)2logd(p))

ll power(ll x,int y=mod-2,int p=mod) {
	ll sum=1;x%=p;
	while (y) {
		if (y&1) sum=sum*x%p;
		x=x*x%p;y>>=1;
	}
	return sum;
}
