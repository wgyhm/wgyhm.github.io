[AGC034E] Complete Compress

*CTT2017 某位歌姬的故事

https://www.luogu.com.cn/problem/P4229

先把区间离散化，这样只有 2q2q2q 个点。

区间 max⁡\maxmax 为一个数，等价于区间所有数都小于等于 max⁡\maxmax，且存在一个数等于 max⁡\maxmax。

先对每个操作做区间覆盖，则每个点有一个取值上限 hih_ihi​。

对于每个点，只可能对 max⁡=hi\max=h_imax=hi​ 的区间有贡献。考虑把对于每个值把这样的区间拿出来。问题转化为了一个序列，染黑（存在 hih_ihi​）或者染白，有许多区间限制，每个区间中至少要有一个染黑的，求方案数。

先转化为所有都染白，然后有些点染黑的方案数。令 fif_ifi​ 表示钦定 iii 为结尾且染黑的方案数，再维护一个左端点表示可以转移的区间，再前缀和搞搞就好了。

复杂度 O(qlog⁡q)O(q\log q)O(qlogq)。

加强版：https://www.luogu.com.cn/problem/AT_abc262_h。

[JOI Open 2016] 摩天大楼

插入 dp。同 ZJOI 波浪。

考虑一个把所有元素按照从大到小的顺序放到排列中正确的位置 的过程。那么每次插入一个元素，其所在的连续段就是以其为根在笛卡尔树上的子树。

这么做最后的值域会很小，但是 dp 中存在加减用到的值域会很大。考虑将 dp 差分，这样每次都是加法。

细节比较多。

dp 套 dp

dp 套 dp 是给定一个 DP 问题 A，用另一个 dp 去计算一种可能的 A 的输入，使得 A 的 dp 结果为 xxx。

也就是外层的 dp 的状态是另一个 dp 的结果。

BZOJ3864 Hero meet devil

https://hydro.ac/d/bzoj/p/3864

经典 dp 套 dp。先考虑求 LCS 的 dp。设 fi,jf_{i,j}fi,j​ 表示 ttt 的前 iii 位和 sss 的前 jjj 位的 LCS。

然后把这个第二维状态记录下来。设 Fi,SF_{i,S}Fi,S​ 表示当前考虑 ttt 的前 iii 位，fif_ifi​ 的状态是 SSS 的方案数。

第二维状态看上去是 ∣s∣∣s∣|s|^{|s|}∣s∣∣s∣ ，分析发现相邻两个数的值最多只会差 0/10/10/1，状态存其 dp 值的差分数组即可优化为 2∣s∣2^{|s|}2∣s∣。状态与状态之间转移预处理出来即可 O(1)O(1)O(1) 转移。
