#技术向

这几天忙着做 PJ 了，但是在“三周手搓火箭”的项目上，没有AI是不现实的。但是在使用 Vscode 的 codex 插件时一直在 reconnect。

在排查之后，发现

  • chatgpt 网页版可以正常使用
  • 终端的 codex 可以正常使用
  • IDEA 的 codex 勉强可以正常使用
  • vscode 的 codex 死了

所以问题可能是 vscode 的代理没有设置好。

搜索 proxy，配置 setting.json，加入：

{
	"http.proxy": "http://127.0.0.1:xxxx", 
	"http.proxySupport": "override", 
	"http.systemCerticates": true
}
